This project loads its photos directly from Unsplash/Iconscout/Flaticon URLs
(the same approach as the file you originally shared), so no local images are
required for the site to work — just open index.html and everything loads
from the internet.

If you'd rather host images locally in this folder:
1. Download each image you want from its Unsplash URL in index.html.
2. Save it here, e.g. images/hero-women-salon.jpg
3. Replace the matching <img src="https://images.unsplash.com/..."> in
   index.html with src="images/hero-women-salon.jpg".

This keeps the folder structure ready for local images whenever you want them.
